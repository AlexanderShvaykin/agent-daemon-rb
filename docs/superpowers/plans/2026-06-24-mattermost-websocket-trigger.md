# Mattermost WebSocket Mention Trigger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `mattermost` trigger that runs an agent task when the bot is @-mentioned in an allowlisted channel, replying in the same thread.

**Architecture:** A single Daemon-managed EventMachine reactor thread hosts one `faye-websocket` client per `mattermost` runner. Each client filters `posted` mention events and writes a YAML work-item into that runner's inbox dir. A file-poll consumer runner (`Runner::Mattermost < Runner::File`) processes them sequentially through the backend. The agent replies by writing a message YAML routed back into the thread via the existing Messenger + Mattermost transport (extended for `channel_id` + `root_id`).

**Tech Stack:** Ruby + `eventmachine` and `faye-websocket` (new runtime deps) for the WebSocket; stdlib (`net/http`, `json`, `uri`, `yaml`, `fileutils`) for everything else. Minitest for tests.

## Global Constraints

- **New runtime dependencies are intentional here.** The daemon was previously stdlib-only; this change adds exactly `eventmachine` + `faye-websocket` (for the `mattermost` trigger) and updates `AGENTS.md`/`docs/architecture.md` to say so. Do not add any other runtime gems.
- Every Ruby file starts with `# frozen_string_literal: true`.
- Tests are Minitest (`test/test_*.rb`), no spec DSL. Net::HTTP is stubbed via `stub_net_http` + `FakeHttp`/`FakeSuccess` from `test/test_helper.rb` (Minitest 6 has no mock).
- New lib files must be added to `lib/agent_daemon.rb` with `require_relative` in the same task that creates them, or their tests cannot load the class.
- After Task 1, run tests with `bundle exec` (the suite now loads `faye-websocket`/`eventmachine` through the require chain): `bundle exec rake test`, or a single file with `bundle exec ruby -Ilib -Itest test/test_<name>.rb`.
- Path resolution: `message_dir`/`output_dir` and file-style trigger dirs resolve relative to `project_path`; `prompt_template` relative to the config file's directory.
- Config validation collects ALL errors and raises one `ConfigError` (fail-fast) — preserve this.
- EventMachine's reactor is a process singleton — there is exactly ONE reactor thread for the whole daemon, shared by all Mattermost listeners. Never call `EM.run` per runner.
- This is a published gem: bump `lib/agent_daemon/version.rb` and update `CHANGELOG.md` (final task).
- End every commit message with the trailer:

```ruby
        channel = presence(message_data["channel"])
        user = presence(message_data["user"])
        explicit_id = presence(message_data["channel_id"])

        if channel && user
          raise "message specifies both channel (#{channel.inspect}) and user (#{user.inspect}); refusing to guess a destination"

        channel_id =
          if explicit_id
            explicit_id
          elsif user
            dm_channel_id(user)
          elsif channel
            channel_id_by_name(channel)
          else
            channel_id_by_name(@default_channel)
          end

        body = { channel_id: channel_id, message: message_data["message"] }
        root_id = presence(message_data["root_id"])
        body[:root_id] = root_id if root_id

        post("/api/v4/posts", body)
      end
```

```ruby
    def build_trigger(raw_trigger, name = nil)
      return {} unless raw_trigger.is_a?(Hash)

      case raw_trigger["type"]
      when "tracker"
        deep_merge(TRACKER_TRIGGER_DEFAULTS, raw_trigger)
      when "file"
        trigger = deep_merge(FILE_TRIGGER_DEFAULTS, raw_trigger)
        resolve_trigger_dirs(trigger)
      when "mattermost"
        trigger = deep_merge(MATTERMOST_TRIGGER_DEFAULTS, raw_trigger)
        base = name.to_s.empty? ? "mentions" : "mentions/#{name}"
        trigger["input_dir"]   ||= "#{base}/inbox"
        trigger["archive_dir"] ||= "#{base}/done"
        trigger["failed_dir"]  ||= "#{base}/failed"
        resolve_trigger_dirs(trigger)
      else
        raw_trigger
      end
    end

    def resolve_trigger_dirs(trigger)
      %w[input_dir archive_dir failed_dir].each do |key|
        if trigger[key].is_a?(String) && !trigger[key].empty?
          trigger[key] = File.expand_path(trigger[key], @data["project_path"] || "")
        end
      end
      trigger
    end
```

```ruby
# frozen_string_literal: true

require "yaml"

require_relative "file"

module AgentDaemon
  module Runner
    # Consumes mention work-items written by Mattermost::Listener. Inherits the
    # entire inbox-poll / archive / failed / attempt-tracking machinery from
    # Runner::File; only the prompt rendering differs — the YAML fields the
    # listener captured (message, channel_id, root_id, sender, channel_name,
    # post_id) become template variables so the prompt can instruct the agent
    # to reply into the originating thread.
    class Mattermost < File
      private

      def render_prompt(path)
        data = YAML.safe_load_file(path) || {}
        variables = base_template_variables.merge(data.transform_keys(&:to_s))
        @prompt_template.render(variables)
      end
    end
  end
end
```

```ruby
# frozen_string_literal: true

require "net/http"
require "json"
require "uri"
require "time"
require "yaml"
require "fileutils"

require "eventmachine"
require "faye/websocket"

module AgentDaemon
  module Mattermost
    # Per-runner handler for the bot WebSocket. NOT a thread — it is hosted inside
    # the single shared EventMachine reactor (Mattermost::Reactor), because EM's
    # reactor is a process singleton. Resolves the bot id once (blocking, before
    # the reactor starts), then on each `posted` event filters for an allowlisted
    # mention of the bot and writes a work-item YAML the consumer reads.
    # Communicates with the rest of the daemon only through the filesystem.
    class Listener
      BACKOFF_START = 1
      BACKOFF_MAX = 30

      def initialize(trigger_config, shutdown_flag)
        @base_url = URI(trigger_config.fetch("base_url"))
        @token = trigger_config.fetch("token")
        @channels = trigger_config.fetch("channels")
        @input_dir = trigger_config.fetch("input_dir")
        @seen_dirs = [
          trigger_config.fetch("input_dir"),
          trigger_config.fetch("archive_dir"),
          trigger_config.fetch("failed_dir")
        ]
        @shutdown_flag = shutdown_flag
        @backoff = BACKOFF_START
      end

      # Resolve the bot id with a blocking HTTP call. Call before the reactor
      # starts so the reactor thread never blocks on network IO.
      def prepare
        bot_id
        self
      end

      # Open the WebSocket and wire callbacks. Must run inside the EM reactor.
      def start
        ws = Faye::WebSocket::Client.new(websocket_url, nil, ping: 30)
        ws.on(:open)    { authenticate(ws) }
        ws.on(:message) { |event| on_message(event.data) }
        ws.on(:close)   { schedule_reconnect }
      end

      # Decode one raw text frame and route it. Public seam for unit tests.
      def on_message(raw)
        event = parse(raw)
        handle_event(event) if event
      end

      def handle_event(event)
        return unless event["event"] == "posted"

        data = event["data"] || {}
        post = parse(data["post"]) || {}
        return if post["user_id"] == bot_id
        return unless @channels.include?(data["channel_name"])
        return unless mentioned?(data)

        write_work_item(post, data)
      end

      private

      def authenticate(ws)
        @backoff = BACKOFF_START
        ws.send(JSON.generate(
          seq: 1,
          action: "authentication_challenge",
          data: { token: @token }
        ))
      end

      def schedule_reconnect
        return if @shutdown_flag.value

        delay = @backoff
        @backoff = [@backoff * 2, BACKOFF_MAX].min
        Log.warn("[Listener] disconnected, reconnecting in #{delay}s")
        EM.add_timer(delay) { start unless @shutdown_flag.value }
      end

      def websocket_url
        scheme = @base_url.scheme == "https" ? "wss" : "ws"
        host = @base_url.port ? "#{@base_url.host}:#{@base_url.port}" : @base_url.host
        "#{scheme}://#{host}/api/v4/websocket"
      end

      def mentioned?(data)
        raw = data["mentions"]
        return false unless raw

        mentions = parse(raw)
        mentions.is_a?(Array) && mentions.include?(bot_id)
      end

      def write_work_item(post, data)
        post_id = post["id"]
        filename = "#{post_id}.yml"
        return if already_seen?(filename)

        FileUtils.mkdir_p(@input_dir)
        root = post["root_id"].to_s.empty? ? post_id : post["root_id"]
        content = {
          "message" => post["message"],
          "channel_id" => post["channel_id"],
          "root_id" => root,
          "sender" => data["sender_name"],
          "channel_name" => data["channel_name"],
          "post_id" => post_id,
          "created_at" => Time.now.iso8601
        }
        ::File.write(::File.join(@input_dir, filename), content.to_yaml)
        Log.info("[Listener] wrote mention #{post_id} from #{data['sender_name']} in #{data['channel_name']}")
      end

      def already_seen?(filename)
        @seen_dirs.any? { |dir| ::File.exist?(::File.join(dir, filename)) }
      end

      def bot_id
        @bot_id ||= http_get("/api/v4/users/me").fetch("id")
      end

      def parse(raw)
        JSON.parse(raw) if raw
      rescue JSON::ParserError
        nil
      end

      def http_get(path)
        req = Net::HTTP::Get.new(path)
        req["Authorization"] = "Bearer #{@token}"
        response = http.request(req)
        unless response.is_a?(Net::HTTPSuccess)
          raise "Mattermost GET #{path} returned #{response.code}"
        end
        JSON.parse(response.body.to_s)
      end

      def http
        @http ||= begin
          h = Net::HTTP.new(@base_url.host, @base_url.port)
          h.use_ssl = @base_url.scheme == "https"
          h.open_timeout = 10
          h.read_timeout = 10
          h
        end
      end
    end
  end
end
```

```ruby
# frozen_string_literal: true

require "eventmachine"

module AgentDaemon
  module Mattermost
    # The single EventMachine reactor thread for the whole daemon. EM's reactor
    # is a process singleton, so all Mattermost listeners share one reactor
    # rather than each owning a thread. Bridges the daemon's cooperative
    # shutdown: a 1s periodic timer stops the reactor when the flag flips.
    class Reactor
      def initialize(listeners, shutdown_flag)
        @listeners = listeners
        @shutdown_flag = shutdown_flag
      end

      def run
        Log.info("[Reactor] Thread started (#{@listeners.size} listener(s))")
        ready = prepare_listeners

        EM.run do
          EM.add_periodic_timer(1) { EM.stop if @shutdown_flag.value }
          ready.each(&:start)
        end

        Log.info("[Reactor] Thread stopping gracefully")
      end

      private

      # Resolve each listener's bot id before the reactor starts so no blocking
      # HTTP happens on the reactor thread. A listener that fails to prepare is
      # logged and skipped rather than taking down every bot.
      def prepare_listeners
        @listeners.select do |listener|
          listener.prepare
          true
        rescue => e
          Log.error("[Reactor] listener prepare failed, skipping: #{e.message}")
          false
        end
      end
    end
  end
end
```
